# Молоточки

## Обзор

Производство - это один из основных параметров ваших городов. Оно нужно для постройки зданий, улучшений зданий в городе с помощью команды /t upgrade(улучшенные здания дают больше соотвествующих бонусов, с улучшениями можно ознакомиться на странице зданий), создания юнитов в [казармах](../../osnovnye-sooruzheniya/drevnii-mir/baraki.md) и создания оружия и брони в [кузнице](../../osnovnye-sooruzheniya/antichnost/kuznica.md).

### Источники производства:

Некоторые здания увеличивают количество генерируемого производства в городе, к примеру [Шахта](../../osnovnye-sooruzheniya/drevnii-mir/shakhta.md), [Кузница](../../osnovnye-sooruzheniya/antichnost/kuznica.md). А так же некоторые Чудеса света, такие как [Пирамиды](../../nacionalnye-chudesa/kolizei-4.md).

Бонус к производству так же приносят некоторые торговые ресурсы.

Уровень культуры города и выбор биома для его постановки так же влияет на производство.
