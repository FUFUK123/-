# Население города

## Население города <a href="#firstheading" id="firstheading"></a>

_Население_ - абстрактные жители вашей цивилизации. Это не живые игроки, а игровая механика, отражающая развитие города. Изначально в городе есть 1 житель. Каждый житель:

* Даёт 1 слот города для особых построек
* Потребляет 50 (кроме первого жителя)
* Каждый житель дает 1 несчастье

Население требуется для постройки:

* [Коттеджей](../../osnovnye-sooruzheniya/antichnost/bakaleya.md)
* [Шахт](../../osnovnye-sooruzheniya/drevnii-mir/shakhta.md)
* [Рыбных ферм](../../osnovnye-sooruzheniya/drevnii-mir/rybnaya-ferma.md)

и тд

Здания, дающие бонусы за население:

* [Библиотека](../../osnovnye-sooruzheniya/antichnost/biblioteka.md): +10 за каждого ![](<../../.gitbook/assets/image (188).png>)
* [Университет](../../osnovnye-sooruzheniya/srednie-veka/universitet.md): +15 за каждого ![](<../../.gitbook/assets/image (189).png>)
* [Обсерватория](../../osnovnye-sooruzheniya/srednie-veka/universitet-7.md): +150 (фиксированный бонус)
* [Лаборатория](../../osnovnye-sooruzheniya/industrialnaya-era/muzei-5.md): +0.5% за каждого ![](<../../.gitbook/assets/image (190).png>)
* [Школа](../../osnovnye-sooruzheniya/industrialnaya-era/muzei-1.md):  +20 за каждого ![](<../../.gitbook/assets/image (194).png>)
* [Цех](../../osnovnye-sooruzheniya/srednie-veka/universitet-1.md): +0.5% за каждого ![](<../../.gitbook/assets/image (191).png>)
* И некоторые чудеса света

Торговые ресурсы, дающие скидки на население:

* &#x20;![](<../../.gitbook/assets/image (195).png>) Рыба : -2.5% стоимости роста за каждую (макс. 4)
* &#x20;![](<../../.gitbook/assets/image (196).png>)Какао: -10% стоимости роста (не складывается)
* &#x20;![](<../../.gitbook/assets/image (197).png>)Гвоздика: -10% стоимости роста (не складывается)

Рост населения:
