# Урожайность

## Обзор

Пища - это один из основных параметров ваших городов. Пища нужна для увеличения числа [населения вашего](urozhainost.md) города. Так же пища влияет на скорость роста культур в чанке здания [Ферма](../../osnovnye-sooruzheniya/drevnii-mir/ferma.md) и на время создания [поселенцев](../../yunity/poselenec.md).

### Источники пищи:

Некоторые здания увеличивают количество генерируемой урожайности в городе, к примеру [Пастбище,](../../osnovnye-sooruzheniya/drevnii-mir/bank.md) [Водяная мельница](../../osnovnye-sooruzheniya/antichnost/vodyanaya-melnica.md). А так же некоторые Чудеса света, такие как [Висячие Сады](../../nacionalnye-chudesa/kolizei-1.md).

Бонус к пище так же приносят некоторые торговые ресурсы.

Уровень культуры города и выбор биома для его постановки так же влияет на пищу.

Каждый[ житель](urozhainost.md) потребляет пищу.
