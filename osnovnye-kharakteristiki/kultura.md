# Культура

_Культура_ - один из ключевых ресурсов вашей цивилизации. Она накапливается в городах и влияет на их территорию. Чем выше уровень культуры города, тем больше земель он контролирует. Для получения информации о местности вокруг вас используется команда: /area уровень культуры. Она выводит суммарные статы для уровня культуры города при стандартном счастье, а так же показывает торговые ресурсы, которые попали радиус культуры.

Зачем нужна культура? Культура нужна для увеличения стат города, а так же каждый уровень культуры Капитолия требуется для принятия разных общественных институтов. Базово каждая Цивилизация имеет 0.5 очка общественного института. Общественные институты определяют общую тактику для вашей игры.

Уровни культуры города: Уровень культуры представляет собой квадрат со стороной равной радиусу культуры(в чанках) и с центром в центре капитолия/ратуши
