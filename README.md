### Чем отличается от Minecraft Vanilla?

{% hint style="info" %}
Для оптимизации игрового процесса были внесены определенные изменения.
{% endhint %}

<h4 align="center">Отличия от Minecraft Vanilla</h4>

Энд и Ад на сервере отключены.&#x20;

Система опыта и зачарований полностью переработана. Опыт заменён монетами, а зачаровывать предметы можно только в Библиотеке.

Стандартные рецепты создания экипировки недоступны. Исключение составляют лишь кожаная броня, а также деревянный и каменный мечи. Вместо привычной системы действует пять тиров экипировки , которые открываются по мере изучения новых технологий.

Обычные мобы отключены. Их место заняли уникальные кастомные существа, разделённые на четыре тира, соответствующие уровням экипировки. Подробнее об этом можно узнать в соответствующем [разделе](obshaya-informaciya/moby.md).

Выращивание сельскохозяйственных культур доступно только в специальной постройке — [Ферма](osnovnye-sooruzheniya/drevnii-mir/ferma.md).

Разведение животных возможно исключительно в постройке [Пастбище.](osnovnye-sooruzheniya/drevnii-mir/bank.md)

После основания цивилизации открывается доступ к команде /town claim, позволяющей приватить территорию по чанкам. С полным списком доступных команд можно ознакомиться в соответствующем разделе.

Телепортация к другим игрокам отключена.

Некоторые предметы имеют изменённые рецепты крафта.  Полный список изменённых рецептов можно посмотреть с помощью команды /res book.
