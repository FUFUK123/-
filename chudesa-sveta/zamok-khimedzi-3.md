# Всемирный банк

| Требуемая технология | **Всемирный банк (Глобализация + Коммуникации )** |
| -------------------- | ------------------------------------------------- |
| Стоимость            | **15.000.000 монет**                              |
| Размер               | **4х4**                                           |
| Налог                | **-**                                             |
| Молоточки            | **500,000**                                       |
| Прочность            | **5000 (Регенерация 6 прочности в секунду)**      |
| Число победных очков | **2**                                             |
| Ограничение (кол-во) | **1 (на Мир)**                                    |

### Описание

**Всемирный банк** — одна из основных финансовых структур в мире!

### Особенности

* Чудо света (можно построить только одно на весь мир)

### Модификации и эффекты

* Позволяет покупать [победные очки](../upravlenie-gorodom-i-civilizaciei/diplomatiya/pobeda.md) за деньги. Цена 1 очка - 10.000.000(+15.000.000 за каждое новое)

### Регенерация

* Регенерация прочности: +6 в тик
