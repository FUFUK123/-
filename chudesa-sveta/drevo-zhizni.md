# Мачу-Пикчу

| Размер               | **4х4**                                       |
| -------------------- | --------------------------------------------- |
| Требуемая технология | **Мачу-Пикчу (Мировая торговля + Инженерия)** |
| Стоимость            | **2000000 монет**                             |
| Налог                | **-**                                         |
| Молоточки            | **200,000**                                   |
| Прочность            | **5000 (Регенерация 6 прочности в секунду)**  |
| Число победных очков | **1**                                         |
| Ограничение (кол-во) | **1 (на Мир)**                                |

{% hint style="danger" %}
**Внимание! Вы можете построить только 2 чуда света от одного города!**
{% endhint %}

***

_**Мачу-Пикчу**_ - одно из чудес света, древний город инков в Андах. Это чудо увеличивает торговлю, даёт счастье, культуру и науку за каждый торговый ресурс.

**Модификации и эффекты:**

* Торговля: +30%
* <mark style="color:$warning;">Счастье (на Цивилизацию): +5</mark>![](<../.gitbook/assets/image (156).png>)
* <mark style="color:pink;">Культура (на Цивилизацию): +75</mark>![](<../.gitbook/assets/image (157).png>) за каждый торговый ресурс
* <mark style="color:blue;">Наука (на Цивилизацию): +25</mark>![](<../.gitbook/assets/image (158).png>) за каждый торговый ресурс

**Регенерация**

* Регенерация прочности: +4 в тик

**Примечание:**

* Чудо света (можно построить только одно на весь мир)
