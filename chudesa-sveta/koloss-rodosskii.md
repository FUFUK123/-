# Нотр-Дам

| Размер               | **4х4**                                |
| -------------------- | -------------------------------------- |
| Требуемая технология | **Нотр-Дам (Ренессанс + Конституция)** |
| Стоимость            | **5000000 монет**                      |
| Налог                | **-**                                  |
| Молоточки            | **450000**                             |
| Прочность            | **5000**                               |
| Число победных очков | **4**                                  |
| Ограничение (кол-во) | **1 (на мир)**                         |

{% hint style="danger" %}
**Внимание! Вы можете построить только 2 чуда света от одного города!**
{% endhint %}

***

### Особенности

* Чудо света (можно построить только одно на весь мир)

### Зачарования

* Защита от огня 2

Зачарования автоматически появятся в меню [библиотеки](../osnovnye-sooruzheniya/antichnost/biblioteka.md) в вашей Цивилизации

### Модификации и эффекты

* Несчастье и налоги за объявление войны Цивилизации с чудом света Нотр-Дамм: x2
* Время анархии при смене политического строя: -25%
* Сохранение уникальный победных очков во время войны: 25%

### Регенерация

* Регенерация прочности: +6 в тик
