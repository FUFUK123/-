# Башня разведчиков

| Размер               | **1х1**               |
| -------------------- | --------------------- |
| Необходимое здание   | **-**                 |
| Требуемая технология | **Каменная кладка**   |
| Стоимость            | **30000 монет**       |
| Налог                | **1500 монет /сутки** |
| Молоточки            | **3000**              |
| Прочность            | **500**               |
| Очки                 | **1000**              |
| Ограничение (кол-во) | **4**                 |

### Обзор <a href="#obzor" id="obzor"></a>

Башня Разведчиков - военная структура, которая показывает координаты (x,y,z) врагов в пределах культуры Вашей Цивилизации. Тем самым Вы можете найти врага и убить его.&#x20;

Башня разведчиков — одно из основных военных сооружений вашей цивилизации. Его главная задача — докладывать о пересечении врагами территории вашей цивилизации, благодаря чему вы сможете быстро найти врага!

Примечания:

* Дальность: 300 блоков (квадрат со стороной 300, башня разведчиков в центре квадрата)
* Скорость разведки: задаётся командой. Изначально: 30 секунд

Вид доклада башни разведчиков, который показывается в чате:

```
Башня разведчиков засекла игрока [Имя] (HOSTILE) на координатах (x, y, z) в городе [Название]
```
