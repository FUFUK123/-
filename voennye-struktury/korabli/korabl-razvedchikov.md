# Корабль разведчиков

| Размер               | **2х1**               |
| -------------------- | --------------------- |
| Необходимое здание   | **Морской порт**      |
| Требуемая технология | **Мореплавание**      |
| Стоимость            | **25000 монет**       |
| Налог                | **1500 монет /сутки** |
| Молоточки            | **1,550**             |
| Прочность            | **500**               |
| Ограничение (кол-во) | **4**                 |

**Корабль разведчиков** — одно из основных военно-морских сооружений вашей цивилизации. Его главная задача — докладывать о пересечении врагами территории вашей цивилизации, благодаря чему вы сможете быстро найти врага!

**Примечания:**

* Дальность: 300 блоков (квадрат со стороной 300, корабль разведчиков в центре квадрата)
* Скорость разведки: задаётся командой. Изначально: 30 секунд

**Вид доклада корабля разведчиков, который показывается в чате:**

```
Корабль разведчиков засёк игрока [Имя] (HOSTILE) на координатах (x, y, z) в городе [Название]
```
