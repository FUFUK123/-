### Описание <a href="#opisanie" id="opisanie"></a>

_Библиотека_ - одно из зданий, которое просвещает вашу цивилизацию и способствует её развитию. Многие жители приходят сюда и берут интересные для себя книги, тем самым обучаясь сами, а также оставляют свои книги, обучая других. Благодаря этим действиям и происходит просвещение жителей. Многие маги хранят свои заклинания в библиотеке, из-за чего это единственное место, где можно зачаровать предметы.

Команды:

* /t upgrade list - Показывает список доступных улучшений
* /t upgrade start \[Зачарование]\[Уровень зачарования (Римскими цифрами)] - Купить зачарование для библиотеки
* /t upgrade start Библиотека \[2 - 5] - Повысить уровень Библиотеки
