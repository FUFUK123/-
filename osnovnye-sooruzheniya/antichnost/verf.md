### Описание <a href="#opisanie" id="opisanie"></a>

**Банк** — центр экономического развития вашего города. Является крайне важной и полезной структурой, обладающей множеством различных торговых функций, эффективность которых зависит от уровня банка.

Обмен: Банк обменивает полезные рудные ископаемые (железо, золото, алмазы, изумруды) на монеты. Для осуществления обмена возьмите предмет в руку и кликните по табличке правой кнопкой мыши.

**Формула курса обмена:**

```
Курс обмена = Базовый курс обмена * [1 + (0.05 * (количество бонусов "Бартер"))]
```

Примечание: Эффект «Бартер» увеличивает обменный курс на 5% от базовой ставки.

**Команды:**

```
/t upgrade start Банк [2-10]
```
