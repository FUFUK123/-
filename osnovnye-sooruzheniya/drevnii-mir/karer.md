# Карьер

|                      |                       |
| -------------------- | --------------------- |
| Размер               | **1х1**               |
| Необходимое здание   | **-**                 |
| Требуемая технология | **Добыча руды**       |
| Стоимость            | **12500 монет**       |
| Налог                | **1000 монет /сутки** |
| Молоточки            | **750**               |
| Прочность            | **200**               |
| Очки                 | **700**               |
| Ограничение (кол-во) | **2**                 |

Карьер — производственная структура для добычи камня и каменных ископаемых. Работает автоматически; требуется лишь заменять инструмент.

Использование: Положите новые кирки в сундук, после чего карьер начнёт работу.
