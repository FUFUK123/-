# Карьер

|                      |                       |
| -------------------- | --------------------- |
| Размер               | **1х1**               |
| Необходимое здание   | **-**                 |
| Требуемая технология | **Добыча руды**       |
| Стоимость            | **25000 монет**       |
| Налог                | **3000 монет /сутки** |
| Молоточки            | **3000**              |
| Прочность            | **200**               |
| Очки                 | **700**               |
| Ограничение (кол-во) | **1**                 |

Карьер — производственная структура для добычи камня и каменных ископаемых. Работает автоматически; требуется лишь заменять инструмент.

Использование: Положите новые кирки в сундук, после чего карьер начнёт работу.

Шансы (1 уровень):

| Ископаемое    | Шанс |
| ------------- | ---- |
| Булыжник      | 80%  |
| Другой камень | 15%  |
| Уголь         | 5%   |
| Обсидиан      | 0.5% |

Уровни карьера:

| Уровень | Кирка      | Стоимость | Производство | Технология       |
| ------- | ---------- | --------- | ------------ | ---------------- |
| 1       | Деревянная | -         | -            | Добыча руды      |
| 2       | Каменная   | 10000     | 500          | Обработка бронзы |
| 3       | Железная   | 20000     | 1000         | Обработка железа |
| 4       | Алмазная   | 30000     | 2500         | Сталеварение     |

Команды:

```
/t upgrade start Карьер [2 - 4]
```
