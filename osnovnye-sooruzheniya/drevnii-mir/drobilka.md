# Дробилка

|                      |                       |
| -------------------- | --------------------- |
| Размер               | **1х1**               |
| Необходимое здание   | **-**                 |
| Требуемая технология | **Добыча руды**       |
| Стоимость            | **12500 монет**       |
| Налог                | **1000 монет /сутки** |
| Молоточки            | **750**               |
| Прочность            | **200**               |
| Ограничение (кол-во) | **2**                 |

Дробилка — завод по обработке каменных ископаемых (булыжник, гранит, диорит, андезит, обсидиан) и добыче руд.

Использование: Положите булыжник в специальный сундук. Дробилка заберёт его и вернёт ресурсы в специальный сундук.

Уровни дробилки:

| Уровень | Что дробит (включая предыдущий)      | Стоимость     | Производство  | Технология       |
| ------- | ------------------------------------ | ------------- | ------------- | ---------------- |
| 1       | Булыжник, обожжённая глина, песчаник |             - |             - | Добыча руды      |
| 2       | Гранит                               | 5000          | 1000          | Обработка бронзы |
| 3       | Диорит                               | 10000         | 2000          | Обработка железа |
| 4       | Андезит                              | 20000         | 3000          | Литье металлов   |
| 5       | Обсидиан                             | 40000         | 5000          | Порох            |
