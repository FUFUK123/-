# Шахта

|                      |                       |
| -------------------- | --------------------- |
| Размер               | **1х1**               |
| Необходимое здание   | **-**                 |
| Требуемая технология | **Добыча руды**       |
| Стоимость            | **30000 монет**       |
| Налог                | **2500 монет /сутки** |
| Молоточки            | **1500**              |
| Прочность            | **300**               |
| Ограничение (кол-во) | **50**                |

_<mark style="color:orange;">Шахта</mark>_ - промышленное здание для увеличение производства города. Шахта потребляет редстоун со склада и производит продукцию, необходимую для развития вашей цивилизации. Чем выше уровень шахты, тем больше ресурсов она потребляет и тем больше продукции производит.

Особенности:

* Занимает слот города
* Эффективность может быть улучшена торговыми ресурсами

Уровни Шахты:

| Уровень | Потребление редстоуна в час | Производство продукции | Часы до повышения уровня |
| ------- | --------------------------- | ---------------------- | ------------------------ |
| 1       | 16                          | 100                    | 20                       |
| 2       | 32                          | 150                    | 40                       |
| 3       | 64                          | 200                    | 60                       |
| 4       | 128                         | 250                    | 80                       |
| 5       | 256                         | 300                    | 100                      |
| 6       | 512                         | 350                    | 120                      |

Примечание:

* Редстоун для работы шахты хранится в здании [Склад](sklad.md)
* Шахта автоматически потребляет редстоун при наличии
* Пока склад не построен редстоун можно хранить в сундуке здания Шахта
