# Города

### Создание города в цивилизации

Создание города

Поселенца могут создавать лидеры Цивилизации и мэр города в [Казармы](../osnovnye-sooruzheniya/drevnii-mir/baraki.md) за 50.000 (+25.000 за каждый новый) монет и 1000 (+500 за каждый новый) прогресса.

Размещение города

Сперва нужно определиться с местом постройки Вашего города. Различные [биомы](../osnovnye-kharakteristiki/kultura.md#kharakteristiki-biomov) дают свои бонусы к показателям города: [счастью](../osnovnye-kharakteristiki/schaste.md), [науке](../osnovnye-kharakteristiki/nauka/), [производству](../osnovnye-kharakteristiki/molotochki/), [урожайности](../osnovnye-kharakteristiki/urozhainost/). Чтобы определить бонусы от территории, на которой Вы сейчас стоите, введите следующую команду:

```
/area
```

Также более подробно это описано на странице [Культура](../osnovnye-kharakteristiki/kultura.md). После того, как Вы выбрали местность, возьмите в руки поселенца, который выглядит, как железная дверь. Кликните им правой кнопкой по ровной местности (80% блоков ниже уровня Выших ног НЕ должны быть воздухом, водой или лавой) и введите название города. Теперь ждите постройки [ратуши](../voennye-sooruzheniya/glavnye-zdaniya/bashnya-pushkarei.md).

### Управление городом

Информация о городе Вся информация о городе можно узнать командой

```
/t info
```

Торговые ресурсы Когда вы собрали торговый ресурс вам нужно отнести его в ближайшую ратушу и положить в хранилище Цивилизации. После чего через него вы можете положить торговый ресурс в город и сделать его активным. Каждый город вмещает суммарно до 8 торговых ресурсов(не зависимо от типа)

**Улучшения города**

Города необходимо улучшать для того, чтобы можно было строить больше зданий, использовать больше городской территории. Но улучшать нужно и здания, улучшения к которым, как и к городу, открываются после изучения соответствующей [технологии](../osnovnye-kharakteristiki/nauka/). Улучшения стоят денег и требуют производство.

| Команда                     | Описание                                          |
| --------------------------- | ------------------------------------------------- |
| /t upgrade list             | Показывает список доступных улучшений             |
| /t upgrade start <Название> | Позволяет купить улучшение                        |
| /t upgrade completed        | Показывает список купленных улучшений             |
| /t upgrade stop             | Отменяет текущее улучшение города                 |
| /t upgrade progress         | Показывает время до завершения улучшения в городе |
